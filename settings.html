Le serveur ne tourne pas

C’est lui qui sert tes exports aux téléphones. Lance-le une fois dans un terminal, depuis le dossier de l’extension :

cd server
npm install   # la première fois seulement
npm start

Ensuite, active « Démarrer avec le Mac » ci-dessous : tu n’auras plus jamais à le relancer. Cette page se met à jour toute seule.

Ouvrir sur un téléphone

Scanne le QR code avec n’importe quel téléphone connecté au même Wi-Fi. Il marche partout, Android compris.
